# Origen

Deja aquí tus documentos de partida **antes** de decir *inicializa mi base*:

- `curriculum.md` (preferido) o `curriculum.pdf` con texto seleccionable
- `presentacion.md` (carta o bio, si la tienes)

El skill extrae hechos a `base/*.yaml`. No reescribe estos archivos. Si más adelante cambian tus hechos, usa **actualizar base** y, si quieres, sustituye el origen a propósito.
