# Origen

Deja aquí tus documentos de partida **antes** de decir *inicializa mi base*:

- `curriculum.md` (preferido) o `curriculum.pdf` con texto seleccionable
- `presentacion.md` (carta o bio, si la tienes)

Si usas PDF: el texto debe ser seleccionable. En Linux/macOS ayuda tener `pdftotext` (poppler). Un escaneo sin OCR no sirve.

El skill extrae hechos a `base/*.yaml`. No reescribe estos archivos. Si cambian tus hechos: **actualizar base**.

Demo sin tu CV: `sh scripts/demo_smoke.sh` o [`ejemplos/`](../../ejemplos/README.md). Guía: [`docs/usar.md`](../../docs/usar.md).
